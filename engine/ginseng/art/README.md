# Supplied Braille collection

These 18 UTF-8 text assets are the artwork supplied by the user in the conversation. They replace the first set of simple ASCII scenes. Adjacent drawings that were pasted on a shared line have been separated; all nonblank Braille glyphs remain in their original order.

`ginseng.scene_art` names the pieces, pairs them with palettes and renders them. Files retain the supplied padding, including the long empty margin above the cyberpunk portrait. Only the rendered view removes empty outer margins. At full size every remaining glyph is unchanged; smaller views pool dots to retain fine strokes and preserve the whole picture.

Choose any piece under **Ctrl+W → Braille art**, press **a** to cycle, or search **art:** with **Ctrl+P**. The sidebar and boot use the same selection. The wardrobe provides the largest preview.
